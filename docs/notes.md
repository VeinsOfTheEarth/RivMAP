# Notes

This repository is a GitHub-oriented packaging of the original RivMAP MATLAB toolbox.

Packaging changes were intentionally minimal:
- the MATLAB source files were moved to `src/`
- the demo script was moved to `examples/`
- demo data were moved to `data/`
- the walkthrough document was moved to `docs/`
- the demo was updated to use repository-relative paths

No substantive algorithmic refactoring was performed as part of this packaging step.
